# Prior v0.1 product

Prior has one job: let a person create tasks quickly and decide what deserves attention first.

The task model is intentionally binary:

- important + urgent → Focus
- important + not urgent → Plan
- not important + urgent → Quick
- not important + not urgent → Later

Supported actions are create, edit, complete, uncomplete, toggle importance, toggle urgency, and delete. There are no projects, tags, due dates, notes, dashboards, or analytics in v0.1.

Desktop uses a restrained 2×2 matrix. Narrow screens stack the same four groups in priority order. The account surface is deliberately quiet: continue with Google, account identity, and log out.
