# Prior

Downloads for [Prior](https://prior.constantsuchet.fr), the task and habit app.

Get the latest installers (macOS, Windows, Linux, Android) from the [latest release](https://github.com/gh-Constant/prior/releases/latest), or open the app in your browser at <https://app.prior.constantsuchet.fr>.

This repository only holds the releases; the source code is private.
